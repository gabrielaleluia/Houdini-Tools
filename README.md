# Houdini Tools

A collection of Python tools and workflow automation scripts for SideFX Houdini.

## Tools

### Camera

- [Bake Alembic Camera](camera/bake_alembic_camera/README.md) — bake an animated Alembic camera into a native Houdini camera.

## Requirements

Individual tools may have their own requirements and usage instructions. Most tools are intended to run inside Houdini's Python environment.
